# Инсталация

Изисквания:
- Linux, Windows или MacOS система
- Node.js 22 и Git
- Силно препоръчително **pnpm** мениджър на пакети *(npm не се препоръчва)*

1. Клонирайте репото
```bash
git clone https://github.com/NotValra/RoValra.git
```

2. Инсталирайте нужните пакети
```bash
pnpm install
```

3. Копирайте `config.example.js` и `.env.example` и ги преименувайте на `config.js` и `.env`\
Попълнете `.env` с нужните променливи и настройте `config.js` според предпочитанията си.

4. Сглобете (build) езиковите файлове
```bash
pnpm run build:i18n
```

4. Разгърнете командите за един сървър (guild) или глобално
```bash
# разгражда глобално
pnpm run deploy
```

```bash
# разгражда за един guild от config.js
pnpm run deploy-guild
```

5. Стартирайте бота

```bash
pnpm run start
```
